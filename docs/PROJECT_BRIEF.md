# ملخص المشروع التنفيذي — Project Brief

## 1. اسم المشروع
**نظام إدارة مهام الطلاب (Student Task Manager)**

## 2. الرؤية والهدف
بناء أداة أكاديمية بسيطة لكن احترافية وعالية الجودة، تمكن الطلاب من إدارة أعبائهم الدراسية وواجباتهم اليومية في مكان واحد منظم، مع إحصائيات بصرية فورية تشجع على الإنجاز والالتزام بالمواعيد النهائية.

## 3. المشكلة المستهدفة
تشتت متطلبات المقررات الدراسية ومواعيد التسليم بين تطبيقات المحادثة والبريد الإلكتروني، مما يتسبب في نسيان المهام أو تسليمها في أوقات متأخرة وضياع الأولويات.

## 4. الفئة المستفيدة
- طلاب تقنية المعلومات وعلوم الحاسوب والجامعات عموماً.
- المشرفون الأكاديميون لمتابعة تقدم الطلاب.

## 5. القيمة المضافة
- فصل وتصنيف المهام بحسب حالة إنجازها (قيد التنفيذ / مكتملة).
- توفير مؤشرات وإحصائيات رقمية فورية (إجمالي، مكتمل، متبقي).
- واجهة عربية متجاوبة متوافقة مع الأجهزة الذكية.
- معمارية برمجية قياسية قائمة على نمط MVC وممارسات هندسة البرمجيات النظيفة.

## 6. القيود التقنية
- إطار العمل: Laravel 13
- لغة البرمجة: PHP 8.3 / 8.4
- قاعدة البيانات: SQLite
- الواجهة: Blade + Tailwind CSS
